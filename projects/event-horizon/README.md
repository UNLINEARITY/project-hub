# Event Horizon Timer

[Product and screenshots](https://unlinearity.github.io/project-hub/event-horizon/) · [简体中文](https://unlinearity.github.io/project-hub/event-horizon/index-zh-hans.html) · [All apps](https://unlinearity.github.io/project-hub/)

A quiet focus timer for macOS 26+. When work ends, a black hole bends your live desktop and prompts a break.

- Set your own work, growth, and shrinking durations.
- Start with two free black-hole styles and today’s focus statistics.
- Explore six interactive science experiments offline.
- Choose optional, one-time Pro for all nine styles, appearance adjustments, and historical statistics.

Requires a Metal-capable Mac. Preparing for the Mac App Store.
