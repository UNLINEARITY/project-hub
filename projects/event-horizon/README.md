# Event Horizon Timer website / 网站

English and Simplified Chinese product, support, and privacy pages for Event Horizon Timer are maintained here. Product facts and category information live in the root `projects.json`; shared navigation, language links, appearance, and footers are generated by the site builder.

本目录维护 Event Horizon Timer 的中英文产品介绍、支持与隐私政策。项目资料和分类登记在根目录 `projects.json`，导航、语言切换、外观和页脚统一生成。

Run from the Project hub root / 从 Project hub 根目录运行：

```sh
python3 scripts/build.py
python3 scripts/check.py
open site/event-horizon/index-zh-hans.html
```

- `pages/index.html` / `index-zh-hans.html`: product overview and free/Pro boundaries.
- `pages/support.html` / `support-zh-hans.html`: timer, capture, purchasing, and support instructions.
- `pages/privacy.html` / `privacy-zh-hans.html`: the complete privacy policy, kept consistent with the app’s offline policy.
- `assets/app-icon.png`: the actual app icon.

介绍、支持、隐私正文与应用行为保持一致；隐私处理方式变更时，同步更新应用内离线政策和两种语言。只维护本目录的源文件，不编辑生成的 `site/` 页面。

Keep both languages aligned with actual app behavior. When privacy practices change, update the offline in-app policy as well. Edit source files here, not generated `site/` pages.
