### Event Horizon Timer

安静工作，按时休息。自定义工作与休息时长，选择黑洞样式，也可以通过内置交互科普页面探索黑洞物理。

基础计时、两种样式与今天的统计免费。可选的一次性 Pro 购买提供全部九种样式、外观参数调整和历史统计。需要支持 Metal 的 Mac，正在准备 Mac App Store 首发。

[产品介绍与截图](https://unlinearity.github.io/project-hub/event-horizon/index-zh-hans.html) · [使用支持](https://unlinearity.github.io/project-hub/event-horizon/support-zh-hans.html) · [隐私政策](https://unlinearity.github.io/project-hub/event-horizon/privacy-zh-hans.html)

### Picliva · 拾映

在 iPhone 上把照片与实况照片拼成一张图，再为图库腾出空间。横竖拼接、原始画质 JPEG 与 PNG 导出、照片图库整理均免费，没有水印和导出次数限制。

可选的一次性 Pro 购买提供创意布局、裁剪、实况声音与视频整理。界面提供英文、简体中文和日文。

[产品介绍](https://unlinearity.github.io/picliva-site/index-zh-hans.html) · [使用支持](https://unlinearity.github.io/picliva-site/support-zh-hans.html) · [隐私政策](https://unlinearity.github.io/picliva-site/privacy-zh-hans.html) · [日本語](https://unlinearity.github.io/picliva-site/index-ja.html)
